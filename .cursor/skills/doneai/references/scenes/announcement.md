# 内部公告 announcement

## 场景画像

HR、行政、IT、运营团队发布内部通知：假期安排、系统维护、制度变更、搬家通知、团建通知等。核心目标是让通知更正式、更清晰、更容易被群内阅读和转发。

## 触发词

`通知` / `公告` / `放假通知` / `搬家通知` / `制度变更` / `内部公告` / `系统维护`

## 信息结构

| 层级 | 内容 |
|------|------|
| 核心 | 通知标题、关键内容 |
| 强建议 | 生效日期、发布部门 |
| 可选 | 适用人群、联系人、Logo、注意事项 |

缺通知主题时追问。缺日期、部门、适用人群等业务事实时，不编造；用户明确要展示这些信息但未提供时再追问，否则省略对应模块。

## 默认尺寸

| 用途 | 推荐 |
|------|------|
| 默认 / 群内通知 | `poster_vertical`，9:16 |
| 邮件 / 网页 | `presentation`，16:9 |
| 朋友圈 / 群内短通知 | `square`，1:1 |
| 文字较多 | `infographic_long`，默认 9:16；内容很长时 1:2，正文压缩成要点 |

## 通知类型策略

| 类型 | 视觉调性 |
|------|----------|
| 假期/节日 | 轻松、节日元素、暖色 |
| 制度/规则 | 正式、简洁、蓝灰色 |
| 团建/福利 | 活泼、有温度、插画感 |
| 系统维护 | 技术感、深色、图标化 |
| 搬家/空间 | 清爽、地图/建筑/路线元素 |

## 版式策略

- 标题区醒目，避免过度装饰。
- 正文区必须可读，行距充足。
- 日期、时间、地点、影响范围用色块或强调线突出。
- 底部保留落款区域：部门 + 日期。
- Logo 可放顶部或底部，保持克制。

## Prompt 模块

```text
场景/用途：内部公告图。
主请求：{用户要发布的通知目标}。
输入图：{Logo、办公空间图、参考图等按用户图顺序说明用途；无图时省略}。
主体/内容：{通知标题、关键内容；日期、部门、适用人群、联系人、注意事项仅在用户提供或明确要求时写入}。
文字：{需要上图的通知原文或关键句，保持原意和数字准确}。
参考图：{素材库参考图角色；无素材库参考图时省略}。
风格/媒介：{正式/轻松/技术/节日等通知调性}，办公场景可读视觉。
构图/版式：标题区、正文区、重点信息区清晰分隔；落款区仅在用户提供落款信息时出现。
光影/色彩/质感：背景简洁，信息对比清楚，装饰不压文字。
约束：不编造日期、部门、范围、承诺或联系人；文字准确，无水印，无多余文字。
```
