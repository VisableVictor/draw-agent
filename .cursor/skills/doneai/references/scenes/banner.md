# 运营 Banner banner

## 场景画像

产品运营、内部平台团队生成各种 Banner：内部管理后台、钉钉工作台、活动页横幅、网页内部广告位、邮件头图等。核心目标是让用户 5 秒内看懂主题和行动。

## 触发词

`Banner` / `横幅` / `轮播图` / `内部系统Banner` / `后台Banner` / `钉钉工作台` / `广告位` / `内部广告`

## 信息结构

| 层级 | 内容 |
|------|------|
| 核心 | 使用位置、主题内容 |
| 强建议 | 主标题、目标尺寸 |
| 可选 | 副标题、CTA、产品图、人物图、Logo、风格 |

缺主题内容时追问。缺使用位置但不影响出图时，按通用 Banner 处理；用户给了具体广告位、平台或尺寸时再做适配。

## 默认尺寸

| 用途 | 推荐 |
|------|------|
| 默认 | `banner`，2:1 |
| 网页头图 / 活动页 Hero | `web_hero`，21:9 |
| 钉钉工作台 / 后台首页 | `banner`，2:1 |
| 邮件头图 | `presentation`，16:9 |
| 窄条广告位 | `narrow_banner`，21:9，信息极简 |

## Banner 类型

| 类型 | 目标 | Prompt 倾向 |
|------|------|-------------|
| 功能引导型 | 引导了解/使用功能 | 干净、科技感、界面元素 |
| 内容运营型 | 吸引关注内容 | 与主题相关、有故事感 |
| 氛围渲染型 | 节日/主题月氛围 | 主题元素、氛围光效、情绪色彩 |
| 信息通知型 | 传递关键通知 | 简洁、正式、信息优先 |
| 网页广告位型 | 引导行动 | 紧凑布局、对比色 CTA |

## 版式策略

- 主标题 ≤ 6 字最佳。
- 左文右图最稳，居中对称适合通知型，全幅视觉适合氛围型。
- CTA 对比度最高，文案短。
- 背景不能影响文字可读性；必要时加文字底板/阴影。
- 超窄 Banner 信息要极度精简。

## 参考图

- 用户明确要求使用的产品图、人物图、Logo 等按原顺序传入。
- prompt 按用户描述安排图片用途；用户未说明时，不拆分、不追问。
- 素材库按 `workflow.md` 处理，是否使用由 agent 自行决定。

## Prompt 模块

```text
场景/用途：运营 Banner，{使用位置或通用横幅}。
主请求：{用户要传达的主题内容}。
输入图：{产品图、人物图、Logo 等按用户图顺序说明用途；无图时省略}。
主体/内容：{主题、产品、功能、活动或通知信息}。
文字：{主标题、副标题、CTA 仅在用户提供或可直接归纳时写入}。
参考图：{素材库参考图角色；无素材库参考图时省略}。
风格/媒介：{功能引导/内容运营/氛围渲染/信息通知等类型}，适合横幅传播。
构图/版式：匹配目标比例，文字区域清晰，主体和标题有明确视觉焦点，超窄 Banner 保持信息极简。
光影/色彩/质感：背景不影响文字阅读，对比足够，视觉干净。
约束：不添加未提供的品牌口号、价格、活动机制或 CTA；无水印，无多余文字。
```
