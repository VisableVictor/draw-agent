# 通用出图 generic-image

## 场景画像

没有明确办公版式的图片生成：动物、风景、头像、壁纸、人物、物体、插画、照片感画面、海报图、主题图等。

## 触发词

`生成图片` / `画一张` / `出图` / `照片` / `插画` / `小猫` / `风景` / `头像` / `壁纸` / `角色` / `物体` / `海报图` / `主题图`

## 信息结构

| 层级 | 内容 |
|------|------|
| 核心 | 主体/主题 |
| 可选 | 风格、场景、动作、色彩、比例、参考图 |

缺主体/主题时追问。只缺风格、场景、动作或比例时不追问，使用默认值。

## 默认尺寸

| 用途 | 推荐 |
|------|------|
| 默认 / 动物 / 物体 | `square`，1:1 |
| 头像 / 个人资料图 | `avatar`，1:1 |
| 桌面壁纸 / 横向风景 | `desktop_wallpaper`，16:9 |
| 手机壁纸 / 竖图 | `story_vertical`，9:16 |
| 海报感 / 图文卡片 | `poster_compact`，4:5 |
| 海报图 / 主题图 | `poster_compact`，4:5 |
| 产品 / 物体展示 | `product_showcase`，1:1 |
| 产品海报 / 电商竖图 | `product_showcase`，4:5 |

## Prompt 模块

```text
场景/用途：通用图片、主题图、头像、壁纸、照片或插画。
主请求：{用户原始出图目标}。
输入图：{人物、IP、产品、风格参考等按用户图顺序说明用途；无图时省略}。
主体/内容：{主体、主题、动作、场景；用户未给时只补合理的视觉细节}。
文字：{用户明确要求出现的文字；无文字需求时省略并要求不生成文字}。
参考图：{素材库参考图角色；无素材库参考图时省略}。
风格/媒介：{照片/插画/3D/写实/手绘/头像/壁纸等}。
构图/版式：匹配目标比例，主体清晰，背景服务主体，留白自然。
光影/色彩/质感：根据主题补充光影、氛围、色彩和细节质感。
约束：保持用户图中要求一致的主体特征；无水印；无多余文字；不添加与用户目标无关的角色、物体或剧情。
```
