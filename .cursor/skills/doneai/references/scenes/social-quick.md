# 社媒配图 social-quick

## 场景画像

运营日常高频配图，用于微博、小红书、朋友圈、即刻、LinkedIn 动态等。核心目标是快、够好、能发。

## 触发词

`配图` / `发个朋友圈` / `社媒图` / `微博配图` / `小红书图` / `动态配图`

## 信息结构

| 层级 | 内容 |
|------|------|
| 核心 | 内容/心情/主题 |
| 可选 | 平台、文字、风格、参考图 |

`social-quick` 默认不追问；除非用户完全没有提供主题或心情。

## 默认尺寸

| 用途 | 推荐 |
|------|------|
| 默认 / 微博 / 通用社媒 | `square`，1:1 |
| 小红书 / 朋友圈竖图 | `social_portrait`，3:4 |
| Instagram 竖图 / 移动广告卡片 | `social_portrait`，4:5 |
| Story / 短视频封面竖图 | `story_vertical`，9:16 |
| LinkedIn / 横版动态 / 博客封面 | `presentation`，16:9 |

## 类型策略

| 内容类型 | 视觉调性 |
|----------|----------|
| 观点/金句 | 金句卡片，大字 + 简洁背景 |
| 日常记录 | 温暖插画、柔和色调 |
| 行业见解 | 商务简约、几何、低饱和 |
| 情绪表达 | 氛围感、光影、意境 |
| 活动预热 | 更接近 event，但信息更轻 |

## 设计要点

- 速度优先，信息不要过载。
- 文字少而大，适合手机阅读。
- 用户只是表达内容或心情时，不默认把整句写进画面；只有用户明确说"写上"、"文案"、"标题"、"金句"、"配字"时，才把文字作为画面文字。
- `square` 是通用安全方向；小红书/朋友圈可偏竖版。
- 可以做金句卡片，但不要擅自添加用户没给的观点。
- 右下角可留水印/署名空间，除非用户不需要。

## Prompt 模块

```text
场景/用途：社媒配图、朋友圈图、小红书图、动态配图。
主请求：{用户要表达的内容、心情或主题}。
输入图：{自拍、产品、截图、参考图等按用户图顺序说明用途；无图时省略}。
主体/内容：{主题、情绪、观点、场景或画面主体}。
文字：{用户明确要展示的文字；无文字需求时省略并要求不生成文字}。
参考图：{素材库参考图角色；无素材库参考图时省略}。
风格/媒介：{金句卡片/温暖插画/商务简约/氛围感/活动预热等社媒调性}。
构图/版式：手机端可读，主体或大字醒目，背景简洁，有适度留白。
光影/色彩/质感：适合快速发布，干净、有情绪但不过载。
约束：不擅自添加观点、署名、品牌口号或营销信息；无水印，无多余文字。
```
