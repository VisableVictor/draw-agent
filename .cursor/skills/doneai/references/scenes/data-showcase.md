# 数据战报 data-showcase

## 场景画像

运营、市场、销售、产品团队把数据成果做成视觉化图片，用于周报、月报、汇报 PPT、群内同步、朋友圈庆祝。核心目标是让关键数字被第一眼看见，并让数字含义可信。

## 触发词

`数据图` / `战报` / `成绩单` / `里程碑` / `周报配图` / `月报` / `GMV突破` / `业绩`

## 信息结构

| 层级 | 内容 |
|------|------|
| 核心 | 核心数字、数字含义 |
| 强建议 | 时间范围、业务对象 |
| 可选 | 对比基准、增长率、排名、产品截图、来源 |

用户要展示具体数据但缺核心数字或数字含义时追问。若只是要数据感、战报感或汇报视觉氛围，不编造数字，可省略真实指标。

## 默认尺寸

| 用途 | 推荐 |
|------|------|
| 默认 / 周会 / PPT | `dashboard`，16:9 |
| 群内同步 / 朋友圈 | `dashboard`，1:1 |
| 竖版庆祝海报 | `poster_vertical`，9:16 |
| 多指标仪表盘 | `dashboard`，16:9 |
| 中等宽度仪表盘 | `matrix_diagram`，4:3 |
| 长图总结 | `infographic_long`，默认 9:16；内容很长时 1:2 |

## 数据类型策略

| 数据类型 | 表达方式 |
|----------|----------|
| 单一大数字 | 大字报风格，数字占画面视觉中心 |
| 多指标 | 卡片矩阵 / 仪表盘布局 |
| 前后对比 | 左右对比 / 上升箭头 / 趋势线 |
| 里程碑 | 庆祝式主视觉 + 大数字 |
| 中性汇报 | 蓝灰色、沉稳、PPT 友好 |

## 设计要点

- 核心数字占画面宽度 60% 左右。
- 数字必须有上下文，例如 `Q1 GMV 突破 5000 万`，不要只写 `5000 万`。
- 庆祝类可以有光芒、礼花、金色渐变，但避免廉价素材感。
- 中性或负面数据用沉稳专业风格，不强行庆祝。
- 有产品截图时，作为内容素材或背景界面元素，不应压过核心数字。

## Prompt 模块

```text
场景/用途：数据战报或数据展示图。
主请求：{用户要呈现的数据成果、汇报目标或数据氛围}。
输入图：{产品截图、业务截图、参考图按用户图顺序说明用途；无图时省略}。
主体/内容：{核心数字、数字含义、时间范围、业务对象、对比基准等；只写用户提供或可直接归纳的信息}。
文字：{需要上图的数字、指标名、标题和说明，保持原文准确}。
参考图：{素材库参考图角色；无素材库参考图时省略}。
风格/媒介：{庆祝/专业/增长趋势/中性汇报等调性}，数据可视化视觉。
构图/版式：核心数字或核心结论优先；多指标用卡片、趋势线、对比模块或仪表盘结构组织。
光影/色彩/质感：数字突出，层级清楚，背景不干扰阅读。
约束：不编造数字、增长率、排名、来源或时间范围；文字准确，无水印，无多余文字。
```
