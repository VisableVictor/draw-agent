# 信息图 infographic

## 场景画像

运营、产品、市场、HR 等角色把文章、数据、流程、概念可视化为一张图，用于内部分享、社媒传播、汇报展示、知识沉淀。核心目标是：把复杂内容变成好看又好懂的结构图。

## 触发词

`信息图` / `图解` / `流程图` / `思维导图` / `对比图` / `总结图` / `知识卡片` / `图表` / `概念图` / `架构图` / `可视化`

## 信息结构

| 层级 | 内容 |
|------|------|
| 核心 | 主题或原始内容 |
| 强建议 | 布局类型、目标读者 |
| 可选 | 风格、配色、Logo、来源、图表/截图 |

缺主题或原始内容时追问。缺布局、目标读者、配色等信息时不追问，按内容自动组织。

## 默认尺寸

| 用途 | 推荐 |
|------|------|
| 默认 / 标准信息图 | `infographic_standard`，3:4 |
| 长图 / 群分享 / 多步骤流程 | `infographic_long`，默认 9:16；内容很长时 1:2 |
| PPT / 横版展示 | `presentation`，16:9 |
| 知识卡片 | `knowledge_card`，1:1 |
| 竖版知识卡片 | `knowledge_card`，4:5 |
| 对比图 / 象限图 / 矩阵 | `matrix_diagram`，4:3 |
| PPT 对比图 / 横版矩阵 | `matrix_diagram`，16:9 |
| 架构图 / 层级图 | `architecture_wide`，16:9 |
| 超宽架构图 | `architecture_wide`，2:1 |

## 结构化流程

1. 剥离风格词：3D、手绘、扁平、科技感、黑金、多巴胺等。
2. 提取布局意图：时间轴、流程、对比、矩阵、架构、清单等。
3. 提炼主标题：≤ 8 字最佳。
4. 压缩内容：3-5 个视觉化要点。
5. 保留关键数据、逻辑关系、流程步骤。
6. 多于 5 个要点时，建议拆分为多张图或改成长图。

## 布局策略

| 布局 | 适用内容 | Prompt 关键指令 |
|------|----------|-----------------|
| 时间轴 | 发展历程、里程碑 | 节点按时间排列，每个节点包含时间和事件 |
| 流程图 | 操作步骤、审批流 | 步骤用箭头连接，关键节点高亮 |
| 对比图 | A vs B、前后对比 | 左右分栏，共用维度标签 |
| 思维导图 | 知识体系、分类 | 中心主题向外发散，分支颜色区分 |
| 矩阵/象限 | 优先级、多维评估 | 2×2 坐标轴，每象限放对应项 |
| 清单/卡片 | 要点汇总 | 每个要点独立卡片，图标 + 标题 + 简述 |
| 仪表盘 | KPI 总览 | 核心数字大号，次要指标环绕 |
| 架构/层级 | 系统架构、组织结构 | 层级从上到下或左到右，连线清楚 |

## 设计要点

- 信息可读性 > 视觉炫技。
- 主标题最大，占据显著位置。
- 每个模块之间要有清晰分隔。
- 颜色不超过 3-4 种主色。
- 图标辅助理解，但不喧宾夺主。
- 底部可放来源、Logo 或备注。

## Prompt 模块

```text
场景/用途：信息图、图解、流程图、对比图、思维导图、知识卡片或架构图。
主请求：{用户要可视化的主题或原始内容}。
输入图：{截图、参考图、Logo、产品图等按用户图顺序说明用途；无图时省略}。
主体/内容：{标题、要点、步骤、数据、关系、流程或对比维度；只保留用户提供或可从内容直接提炼的信息}。
文字：{需要上图的标题、节点、标签、数据和说明，保持原文准确}。
参考图：{素材库参考图角色；无素材库参考图时省略}。
风格/媒介：{简洁专业/科技感/手绘/3D/扁平等视觉风格}，信息可读性优先。
构图/版式：按内容选择时间轴、流程、对比、矩阵、清单、仪表盘、架构或知识卡片；模块分隔清楚，阅读路径明确。
光影/色彩/质感：颜色克制，图标辅助理解，背景不抢信息。
约束：不编造事实、数据、来源或逻辑关系；文字准确，无水印，无多余文字。
```

## 示例

用户输入："把我们的内容审核流程做成图解"

结构化结果：

- 风格：简洁专业
- 布局：纵向流程图
- 标题：内容审核流程
- 步骤：提交 → AI 初审 → 人工复审 → 终审确认 → 发布

Prompt：

```text
信息图，简洁专业风格，纵向流程图布局，白色背景，
标题 "内容审核流程"，顶部居中，深色大号字体，
流程从上到下排列，每步用圆角矩形色块包裹：
1. "提交内容"：创作者提交
2. "AI初审"：系统自动检测
3. "人工复审"：编辑团队审核
4. "终审确认"：主编最终确认
5. "正式发布"：内容上线
步骤之间用向下箭头连接，每步配对应图标，
整体排版清晰有节奏感，竖版信息图构图。
```
