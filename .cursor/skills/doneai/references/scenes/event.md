# 活动海报 event

## 场景画像

市场、行政、HR、技术团队为线下活动、线上直播、内部培训、团建、分享会生成活动海报。核心目标是让用户快速知道：什么活动、什么时候、在哪里、谁参与、怎么报名。

## 触发词

`活动海报` / `会议海报` / `沙龙` / `直播海报` / `分享会` / `内部培训` / `团建`

## 信息结构

| 层级 | 内容 |
|------|------|
| 核心 | 活动名称、时间 |
| 强建议 | 地点、主办方 |
| 可选 | 嘉宾、议程、报名方式、二维码区域、Logo |

用户明确要展示活动信息但缺活动名称或时间时追问，最多 1 轮。若只是主题视觉、预热图或氛围海报，不编造时间地点，可省略对应模块。

## 默认尺寸

| 用途 | 推荐 |
|------|------|
| 默认 | `poster_vertical`，9:16 |
| 朋友圈 / 小红书 | `social_portrait`，3:4 |
| PPT / 投屏 | `presentation`，16:9 |
| 活动页头图 | `web_hero`，21:9 |

## 视觉策略

| 活动类型 | 视觉调性 |
|----------|----------|
| 技术沙龙 | 科技感、深色系、代码/光线/网格元素 |
| 内部培训 | 轻松、亲切、暖色、插画感 |
| 线上直播 | 动感、年轻、荧光点缀 |
| 部门活动/团建 | 温暖、团队感、活力色彩 |
| 对外会议 | 专业、正式、品牌感克制 |

## 版式策略

- 主标题最大，通常放顶部或中部视觉焦点。
- 时间和地点紧跟主标题，不能被装饰遮挡。
- 嘉宾信息用头像 + 姓名 + 头衔，头像风格统一。
- 只有用户提供或要求报名方式、二维码、报名入口、CTA 时，才在底部放报名或二维码区域。
- Logo 放顶部或底部角落，不抢主标题。

## 参考图

- 用户明确要求使用的嘉宾照片、Logo、场地图等按原顺序传入。
- 素材库按 `workflow.md` 处理，是否使用由 agent 自行决定。
- prompt 中按输入顺序说明图片用途；素材库参考图只说明参考图角色。

## Prompt 模块

```text
场景/用途：活动海报或活动主题图。
主请求：{用户要生成的活动视觉目标}。
输入图：{嘉宾照片、Logo、场地图、IP 图等按用户图顺序说明用途；无图时省略}。
主体/内容：{活动名称、主题、时间、地点、主办方、嘉宾、议程、报名方式等；只写用户提供或明确要求展示的信息}。
文字：{需要上图的标题、时间地点、嘉宾名、CTA 等，保持原文准确}。
参考图：{素材库参考图角色；无素材库参考图时省略}。
风格/媒介：{科技感/温暖/正式/活力/节日氛围等活动调性}。
构图/版式：主标题或主题视觉优先；时间地点、嘉宾、议程作为次级信息；报名、二维码或 CTA 仅在用户提供或明确要求时出现。
光影/色彩/质感：层级清楚，主题氛围明确，装饰不遮挡文字。
约束：不编造时间、地点、嘉宾、主办方、报名入口或二维码；文字准确，无水印，无多余文字。
```
