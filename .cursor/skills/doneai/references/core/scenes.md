# 场景索引

场景识别、关键信息和场景文件入口集中在这里。

| 场景 | 触发词 | 关键信息 | 细节 |
|------|--------|----------|------|
| `event` | 活动、会议、沙龙、分享会、直播、培训、团建 | 活动名称、时间 | `../scenes/event.md` |
| `data-showcase` | 数据、战报、GMV、业绩、里程碑、成绩单、周报、月报 | 核心数字、数字含义 | `../scenes/data-showcase.md` |
| `announcement` | 通知、公告、放假、维护、搬家、制度变更 | 通知标题、关键内容 | `../scenes/announcement.md` |
| `social-quick` | 配图、朋友圈、社媒、微博配图、小红书图、动态配图 | 内容/心情 | `../scenes/social-quick.md` |
| `banner` | Banner、横幅、轮播图、后台 Banner、广告位、钉钉工作台 | 使用位置、主题内容 | `../scenes/banner.md` |
| `infographic` | 信息图、图解、流程图、思维导图、对比图、总结图、知识卡片、架构图 | 主题或原始内容 | `../scenes/infographic.md` |
| `generic-image` | 生成图片、画一张、出图、照片、插画、小猫、风景、头像、壁纸、角色、物体、海报图、主题图 | 主体/主题 | `../scenes/generic-image.md` |

## 场景准入

- 触发词只生成候选场景，不能单独决定最终场景。
- 最终场景由用户意图决定，不由信息是否齐全决定。
- 关键信息不齐时，不要直接换场景；先按 `workflow.md` 判断是追问、省略该模块、还是使用默认值。
- 用户只是要一张主题图、海报图、配图或普通图片，且没有表达结构化场景意图时，走 `generic-image` 或更直接的轻量场景。
- 用户明确要某个结构化场景但信息不全时，仍保留该场景；只有缺失会导致无法完成明确目标或必须编造业务事实时才追问。

## 歧义处理

- 命中多个场景：优先选择信息更具体、尺寸更明确的场景；仍会影响关键信息或尺寸时，最多追问一个问题。
- 无法识别但用户要出图：走 `generic-image`。
- 用户说"随便"、"你看着办"：使用合理默认值。
