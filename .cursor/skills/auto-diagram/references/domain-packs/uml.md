# UML Domain Pack

适用于软件设计建模、模块关系、时序交互、部署结构。

## 常见子图型

- Class Diagram
- Sequence Diagram
- Activity Diagram
- State Machine
- Component Diagram
- Deployment Diagram

## 进入信号

- 用户明确说类图、时序图、组件图、部署图
- 重点是软件对象、模块接口、交互顺序
- 需要较正式的建模表达

## 表达原则

- 关系语义要准确，不能用“长得像”替代“表达对”
- 如果读者不是纯技术同学，优先收敛元素数量
- 如果图要拿去汇报，建议补一句主线解读

## 常见失误

- 把概念层和部署层混在一张图里
- 时序图里消息命名过长
- 类图试图把所有类一次性塞完

## 默认建议

- 先明确是哪一种 UML 子图
- 非必要不要混搭多种 UML 语义
- 如果用户要“既规范又好讲”，建议 `UML 正式图 + SVG 总览图`
