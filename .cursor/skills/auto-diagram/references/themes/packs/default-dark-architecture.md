# Default Dark Architecture

## 基本信息

- `id`: `default-dark-architecture`
- `display_name`: `默认深色架构图`
- `kind`: `builtin`
- `status`: `default`
- token 文件：[`assets/themes/default-dark-architecture/theme-pack.json`](../../../assets/themes/default-dark-architecture/theme-pack.json)

## 风格摘要

`石板暗夜底 + 语义色描边 + 微网格舞台 + 技术感标题区 + 克制箭头`

## 适合什么

- 平台架构总览图
- 微服务架构图
- 云架构图
- 安全 / 网络 / 数据平台总图
- 屏幕分享、技术评审、深色舞台汇报

## 不适合什么

- 强咨询感、白底留白型老板汇报
- 温和教育图、杂志感信息图
- 需要明显亲和、柔和、静态海报气质的图

## 视觉特征

- 暗夜底色和细网格，整体更偏 technical stage
- 前后端、数据库、云、安全等角色使用语义分色
- 节点描边清晰，但箭头头部保持克制
- 支持 header / summary cards / footer 的外壳舞台
- 单图默认信息密度为 `中`

## 默认推荐场景

当下面条件同时成立时，可优先推荐它：

- 用户没有给明确风格
- 当前图以技术结构或系统依赖为主
- 需要专业、稳定、快速成图

## 常见覆盖

- 把 summary cards 降为更轻
- 减少 glow / 发光感，保持克制
- 在不改骨架的前提下，对 note card 做更暖或更冷的轻量偏移
