# Default Day Blue

## 基本信息

- `id`: `default-day-blue`
- `display_name`: `默认日间蓝图`
- `kind`: `builtin`
- `status`: `default`
- token 文件：[`assets/themes/default-day-blue/theme-pack.json`](../../../assets/themes/default-day-blue/theme-pack.json)

## 风格摘要

`白底蓝图纸感 + 0066FF 主强调 + 冷灰信息层级 + 轻卡片 + 克制箭头`

## 适合什么

- 白底 / 日间模式的技术架构图
- 老板汇报、评审会、PPT 截图
- 能力图、平台图、现状到目标态图
- 需要更轻、更清楚、更可打印的场景

## 不适合什么

- 依赖夜景氛围感的深色技术舞台
- 需要多语义高饱和对比的安全告警式画面
- 希望整体更工业、更霓虹、更赛博的图

## 视觉特征

- 整体围绕 `#0066FF` 及其邻近蓝系展开
- 页面和卡片更轻，适配白底汇报环境
- 文本层级清楚，但对比比深色版更温和
- 仍然保留可脚本映射的语义角色颜色，只是整体收敛到冷色家族
- 默认信息密度为 `中偏低`

## 默认推荐场景

当下面条件同时成立时，可优先推荐它：

- 用户没有给明确风格
- 目标偏老板 / 评审 / 白底 PPT
- 图需要更明亮、更整洁、更轻的阅读体验

## 常见覆盖

- 提高某一条主链路的蓝色强调
- 压低说明卡数量，做更清爽的老板版
- 在不改蓝色主轴的前提下，把少量强调色往青蓝或钴蓝偏移
