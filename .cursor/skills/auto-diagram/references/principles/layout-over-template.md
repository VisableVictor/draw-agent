# Layout Over Template

- 骨架可以复用思路，不可以复用死板版式
- 布局家族不是模板库
- 主题包也不是模板库；它只能给视觉底座，不能替你决定骨架
- 连线不得穿越文字区；边标签必须位于安全区
- 连线、箭头、边标签不得压在主砖块正文上；宁可绕线、分层、留白，也不要默认穿砖
- 唯一例外是显式标记为 `under-node` 的长箭头主干：它可以在节点下层穿过砖块区域并被节点局部遮挡，但文字、标签、说明卡、摘要卡仍不得被遮挡
- 连线主干只能在锚点处接触 node / group / stage 边缘；沿边框长距离滑行视为未通过
- 对复杂长反馈线、例外线、控制线，允许通过颜色分层增强辨识，而不是一味增加拐弯次数
- 如果母容器一侧出现肉眼可见的大块空白带，说明布局还没把画布吃满，应回到骨架层重排
- 不要默认添加 `1/2/3/4` 这类序号圆点或徽标；只有布局确实无法表达顺序时才考虑加
- 多条语义边不得无理由完全重叠
