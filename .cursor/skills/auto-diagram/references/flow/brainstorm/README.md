# Brainstorm Phase

这是 `auto-diagram` 的固定入口闸门。

## 先读什么

1. [../../shared/interaction-contract.md](../../shared/interaction-contract.md)
2. [../../principles/entry-and-confirmation.md](../../principles/entry-and-confirmation.md)
3. [brainstorm-mode.md](brainstorm-mode.md)
4. 若需要主题包推荐、自定义风格收束或 pack 数量提示，再按需读 [../../themes/README.md](../../themes/README.md)
5. 若需要更稳定的问法骨架，再按需读 [brainstorm-templates.md](brainstorm-templates.md)

## 这一阶段要完成什么

- 锁定 audience、purpose、core message、story axis、style、theme strategy、density、formal notation、must-show / must-not-show
- 产出固定四段回执：
  - `🧾 已知信息回执`
  - `❓ 待确认点`
  - `✨ 增强建议`
  - `🧭 推荐默认方向`
- 如存在明确分叉，优先走菜单式确认

## 不要做什么

- 不要因为用户描述很长就跳过 brainstorm
- 不要在 brainstorm 完成前直接选模板、选后端、写图稿
- 不要把问题变成开放作文题，让用户重写一遍需求
