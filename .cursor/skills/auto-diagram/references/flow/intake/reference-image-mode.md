# Reference Image Mode

如果用户提供参考图，目标是“学习其感觉”，不是机械照抄。

## 先分析，再决定借什么

从参考图中提取：

- 背景类型：纯色 / 渐变 / 纹理 / 氛围感
- 主色与强调色
- 节点形状：矩形 / 胶囊 / 六边形 / 圆环 / 卡片
- 线条风格：直角 / 曲线 / 实线 / 虚线 / 发光
- 排布密度：疏 / 中 / 稠
- 标题和说明区的层级关系
- 是否值得沉淀为以后可复用的主题包

## 借风格，不盲抄骨架

做两个判断：

- 参考图的视觉风格是否适合借用
- 参考图的布局骨架是否适合当前内容

四种处理：

- 风格适合，骨架适合：都可借
- 风格适合，骨架不适合：只借风格
- 风格不适合，骨架适合：只借骨架
- 风格和骨架都不适合：只把它当反例

## 与主题包的关系

- 参考图任务默认走 `reference-derived`
- 这一步的目标是把当前任务的风格学出来，不是立即落库成常驻主题包
- 如果当前任务最终成图效果稳定、风格辨识度高、以后大概率还会复用，可以把它视为 `theme pack candidate`
- `theme pack candidate` 在正式交付前仍然只是当前任务内部状态，不要自动写成新的 resident pack

## 参考图学习结果要落成一句话

在开始生成前，先在自己的推理中收束成一句：

`visual_style_summary: 石墨灰工业底色 + 铜金强调 + 高密豆腐块分层 + 克制箭头`

后续渲染都围绕这句话执行。

## 交付后的升级动作

- 当前任务如果来自参考图，并且大图已经完成交付后，可以补一个选项：
  - `是否把这个风格抽象为常驻主题包，以后都可以选`
- 只有在用户明确同意后，才继续进入主题包命名和落库流程
- 如果用户愿意沉淀，但不想自己起名，可以先给一个短推荐名
