# BPMN Domain Pack

适用于审批流、业务流程规范化、跨角色协作流。

## 进入信号

- 用户明确提到 BPMN
- 流程需要角色泳道、网关、事件、任务表达
- 图要用于业务流程评审或流程规范沉淀

## 表达原则

- 起止事件、任务、网关、泳道职责要清楚
- 不要把所有业务细节都塞进节点文案
- 如果流程很长，优先拆阶段，而不是无限拉长一张图

## 何时不该用 BPMN

- 只是想给老板讲清一条业务链路
- 用户真正想要的是“概览故事图”而非规范流程图
- 角色和分支都很轻，普通流程图已经够用

## 默认建议

- 如果既要规范又要讲清楚，建议 `BPMN 正式图 + SVG 汇报图`
- 先锁定“主路径”和“关键异常分支”
