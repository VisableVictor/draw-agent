# ArchiMate Domain Pack

适用于企业架构分层表达，尤其是业务层、应用层、技术层的正式建模。

## 进入信号

- 用户明确提到 ArchiMate
- 需求重点是企业架构分层和层间关系
- 图要服务正式架构评审，而不是轻量说明

## 表达原则

- 分层必须清楚
- 每层只放该层语义的元素
- 不要把汇报型注释塞满正式图

## 何时不该用 ArchiMate

- 只是想画一个“平台能力总览”
- 主要读者是老板或非专业管理层
- 用户需要强叙事和强视觉引导

## 默认建议

- 正式评审：优先 ArchiMate
- 高层汇报：优先 `SVG 总览图`，必要时附 ArchiMate 版本
