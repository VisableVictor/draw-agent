# Formal Diagram Phase

只有当任务明确命中正式图法时，才进入这一层。

## 先读什么

1. [formal-diagram-modes.md](formal-diagram-modes.md)
2. 只读一个最相关的 domain pack：
   - [packs/uml.md](packs/uml.md)
   - [packs/bpmn.md](packs/bpmn.md)
   - [packs/archimate.md](packs/archimate.md)
   - [packs/cloud.md](packs/cloud.md)
   - [packs/network.md](packs/network.md)
   - [packs/security.md](packs/security.md)
   - [packs/data-analytics.md](packs/data-analytics.md)
   - [packs/iot.md](packs/iot.md)
3. 如需 few-shot 语法锚点，只读一个最相关的 example：
   - `references/formal/examples/*`

## 这一阶段要完成什么

- 明确采用的正式图法
- 明确专业语义优先于画面装饰
- 如需汇报表达，判断是否同时补一张总览图

## 不要做什么

- 不要因为用户说“流程”就默认 BPMN
- 不要因为用户说“架构图”就默认 ArchiMate
- 不要把正式图法和自由装饰图混写成四不像
