# 社交卡片美学指南

> 本文件是 SKILL.md 场景路由的参考。当用户需要生成小红书卡片、Twitter/X 金句卡、社交轮播等固定尺寸的社交分享图时读取此文件。

## 通用约束

- **固定像素尺寸**：社交卡片最终会被截图发出，必须用精确像素宽度，不用百分比/响应式
- **截图友好**：整张卡片在一个可视区域内，不需要滚动
- **手机可读性**：字号大（正文不小于 text-xl）、行距宽（leading-relaxed 以上）、对比强——社交平台主要在手机上浏览，小字根本看不清
- **信息密度**：每张卡片只承载一个核心观点，不要塞
- **水印**：右下角小字作者名 / 日期，不影响主体视觉

## 子场景设计思路

### 小红书图文卡片

**触发信号**：用户说"小红书卡片"、"小红书图文"、"XHS card"。

**尺寸**：`w-[1080px] h-[1440px]`（3:4 比例），多张卡片用 flex 纵向排列，方便整体截图也方便单张截图。

**页面结构**：
- **封面（第 1 张）**：巨大标题（text-6xl 以上）+ 1 行副标题 + 一个吸引人的标签（"干货预警" / "建议收藏" / "建议转发"）
- **正文（中间 N 张）**：每张一个核心观点，配 emoji 图标 + 短句描述 + 1-2 个具体例子
- **收尾（最后 1 张）**：总结要点 + 行动号召（关注 / 收藏 / 评论引导）

**数量**：短内容 3-6 张起步，长内容更多。小红书平台单帖最多 18 图，通常 9 张以内最佳。

**设计语言**：
- **配色**：莫兰迪色或粉色系，柔和低饱和。参考调色板：
  - 奶杏：`#F5E6D3` 背景 + `#C9A87C` accent
  - 薄荷：`#E8F5E9` 背景 + `#66BB6A` accent
  - 腮红：`#FCE4EC` 背景 + `#E91E63` accent
- **元素**：圆角（rounded-2xl 以上）、大量留白、柔和阴影
- **字号**：标题 text-5xl~6xl，正文 text-xl~2xl
- **每张卡片右下角**：小水印（作者名 / 日期），`text-xs text-gray-400`

### Twitter / X 金句卡

**触发信号**：用户说"推特卡"、"Twitter card"、"金句卡"、"X card"。

**尺寸**：`w-[1600px] h-[900px]`（16:9 比例），截图后可直接配推文发出。

**布局**：
- **中央**：一句 hero 金句（text-5xl~6xl，font-semibold，限 2-3 行，居中对齐）
- **下方**：作者署名 + 圆形头像占位（w-12 h-12）+ @handle
- **左上角**：小类型标签（"Insight" / "Data" / "Quote"），pill 形状
- **右下角**：品牌水印

**设计语言**：
- **暗色 / 亮色二选一**，根据内容情绪决定：
  - 暗色：深灰底 `#1A1A2E` + 白色文字 + 微光晕
  - 亮色：米白底 `#FAFAF5` + 深色文字 + 柔和阴影
- **背景纹理**（必加其一）：
  - Grid 网格线（细线，opacity 0.05）
  - Noise 噪点
  - Dot pattern
  - 角落微渐变光晕
- **视觉简洁有力**，不要多余装饰元素

### 三联社交轮播

**触发信号**：用户说"轮播"、"carousel"、"三联图"、"Instagram carousel"。

**尺寸**：每张 `w-[1080px] h-[1080px]`（1:1 方形），共 3 张。

**布局**：
- **Card 1**：headline 开头部分 + 品牌 mark（左上角）+ 页码 `1/3`
- **Card 2**：headline 中段 + 视觉重点（图 / 数据 / 对比）+ 页码 `2/3`
- **Card 3**：headline 结尾 + CTA（关注 / 了解更多）+ 循环 icon + 页码 `3/3`

**设计语言**：
- **headline 跨张串联**：三张卡的 headline 拼起来是一句完整的话，每张只显示一段
- **统一调色板**：三张卡共用一套颜色，卡片之间可做渐进色相微调（如 hue 从 220→230→240）
- **品牌一致性**：所有卡片有统一的品牌 mark 位置和字体风格
- **页码指示器**：底部居中 dot 或数字，标识当前位置

## 字体推荐

| 子场景 | Display Font | Body Font | Google Fonts 引入 |
|-------|-------------|-----------|-------------------|
| 小红书卡片 | ZCOOL KuaiLe (400) | Noto Sans SC (400/500/700) | `family=ZCOOL+KuaiLe&family=Noto+Sans+SC:wght@400;500;700` |
| Twitter 金句 | Space Grotesk (500/700) | Inter (400/500) | `family=Space+Grotesk:wght@500;700&family=Inter:wght@400;500` |

## 配色 CSS 变量模板

社交卡片建议用 CSS 变量集中管理配色，方便批量换肤：

```css
:root {
  --card-bg: #F5E6D3;           /* 卡片背景 */
  --card-surface: #FFFFFF;      /* 内容区块背景 */
  --card-ink: #2D2A26;          /* 主文字 */
  --card-muted: #8B8579;        /* 次要文字 */
  --card-accent: #C9A87C;       /* 强调色 / 标签底色 */
  --card-line: #E8E0D4;         /* 分割线 / 边框 */
}
```

## 避坑

- **不要用百分比宽度**：社交卡片是截图产物，必须固定像素宽，确保截图尺寸稳定
- **小红书卡片不要在一张里塞太多内容**：宁可多做几张，每张一个观点
- **Twitter 金句不要超过 3 行**：超过就失去了"金句"的冲击力
- **轮播的 headline 必须跨张串联**：如果每张卡是独立标题，就不是轮播而是三张独立卡
- **头像占位用 SVG 圆形**，不要用 broken image icon
- **暗色卡片的文字不要用纯白 `#FFF`**：用 `#F0F0F0` 或 `rgba(255,255,255,0.92)` 更柔和
